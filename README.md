# BitSoul
My student project developed with Godot Engine.
A 2D pixel platformer created as part of my academic project.

Engine: Godot 4.2
Language: GDScript
Art: Aseprite
UI Design: Figma
Genre: 2D Platformer
Visual Style: 1-bit / monochrome pixel art

This project focuses on exploring game development, pixel art, gameplay mechanics, user interface design, and optimization for low-resource devices.
